OVERVIEW: Extract or update the embedded runner binary.

A no-op when the installed runner is already this version: it prints "Runner
already installed at <path>", and --json reports "extracted": false.

USAGE: grantiva runner install [--json] [--verbose] [--quiet]

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --version               Show the version.
  -h, --help              Show help information.
