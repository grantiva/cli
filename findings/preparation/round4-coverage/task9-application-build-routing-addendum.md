## Shared restrictions

Every build below uses the frozen QA CLI/runner home and a fresh scratch copy of frozen demo `84af7581…`; no candidate/source artifact is edited or replaced. Capture copy/input hash, candidate hash, exact argv/MCP requests, cwd/environment, output-root freshness, raw stdout/stderr/JSONL, compiler PID/argv, result and product manifest. Use `cov4-ios` or `cov4-android`, API key unset. One app compiler at a time, excluding source tests and unrelated Android quiet/timing windows. Literal cancellation is its own exclusive build/cancellation window, not an exception allowing concurrent load.

The iOS target is reserved primary26 `cov4-ios-26` / `3B3BBFDB-D435-454F-9DDC-E0CC5EE99E42`, except IOS-014's reserved extra3. Android uses the authenticated current `cov4-android` generation; old PID 82484 is not live ownership. Compile-only Android calls must retain unchanged ADB inventories and never boot/install; reserve shutdown when a literal row requires it. All install/launch operations stay on those exact allocated targets. After any scratch-product install, stop the row-owned app/session and restore the hash-bound frozen `.app`/APK before unrelated behavior rows; retain artifact identity and exact-device install/restore proof. Build-only and failed/cancelled builds may not install their partial product.

Preserve literal configurations/arguments, including absent-config tests. Do not add a config file, selector argument or unsupported flag merely to make a row pass. In a no-config leg whose literal arguments cannot safely select the reserved target under the approved default-device guard, capture the safe refusal/non-pass and return the exact selection conflict to root; never operate an owner device or silently substitute a different request. Missing-config/default-refusal controls gain no permission to compile before their required refusal.

Record unexpected failure and preserve raw evidence; do not fix/rerun the source suite, expand a key or claim a clean gate.
