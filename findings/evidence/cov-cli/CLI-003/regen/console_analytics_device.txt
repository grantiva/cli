OVERVIEW: Show one device's risk profile, compliance status, and recent events.

USAGE: grantiva console analytics device [--json] [--verbose] [--quiet] <key-id>

ARGUMENTS:
  <key-id>                Device key ID.

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --version               Show the version.
  -h, --help              Show help information.
