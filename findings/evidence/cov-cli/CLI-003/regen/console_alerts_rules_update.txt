OVERVIEW: Change a rule's name, threshold, comparison, URL, or active state.

USAGE: grantiva console alerts rules update [--json] [--verbose] [--quiet] <rule> [--name <name>] [--threshold <threshold>] [--comparison <comparison>] [--url <url>] [--active] [--no-active]

ARGUMENTS:
  <rule>                  Rule ID.

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --name <name>
  --threshold <threshold> 0–100.
  --comparison <comparison>
                          gt or gte.
  --url <url>
  --active/--no-active    Activate or deactivate the rule.
  --version               Show the version.
  -h, --help              Show help information.
