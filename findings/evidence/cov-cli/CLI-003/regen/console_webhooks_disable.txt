OVERVIEW: Pause deliveries to a webhook without deleting it.

USAGE: grantiva console webhooks disable [--json] [--verbose] [--quiet] <webhook>

ARGUMENTS:
  <webhook>               Webhook ID.

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --version               Show the version.
  -h, --help              Show help information.
