OVERVIEW: Move a flag environment up or down in the sort order.

USAGE: grantiva console envs reorder [--json] [--verbose] [--quiet] <env> <direction>

ARGUMENTS:
  <env>                   Environment slug (or UUID).
  <direction>             Direction: up or down. (values: up, down)

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --version               Show the version.
  -h, --help              Show help information.
