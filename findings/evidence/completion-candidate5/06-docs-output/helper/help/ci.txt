OVERVIEW: CI pipeline — capture, compare, and upload results.

USAGE: grantiva ci <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  run                     Run full CI pipeline: capture screenshots, compare
                          against baselines, upload results.

  See 'grantiva help ci <subcommand>' for detailed help.
