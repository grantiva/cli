OVERVIEW: Show a device's profile and its recent attestation events.

USAGE: grantiva console devices get [--json] [--verbose] [--quiet] <key-id>

ARGUMENTS:
  <key-id>                The device's App Attest key ID.

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --version               Show the version.
  -h, --help              Show help information.
