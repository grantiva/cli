OVERVIEW: Rename or recolor a flag environment.

USAGE: grantiva console envs update [--json] [--verbose] [--quiet] <env> [--name <name>] [--color <color>]

ARGUMENTS:
  <env>                   Environment slug (or UUID).

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --name <name>           New environment name.
  --color <color>         New display color as a hex code.
  --version               Show the version.
  -h, --help              Show help information.
