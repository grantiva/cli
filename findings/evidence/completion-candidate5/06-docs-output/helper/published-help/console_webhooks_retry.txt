OVERVIEW: Retry a failed delivery.

USAGE: grantiva console webhooks retry [--json] [--verbose] [--quiet] <webhook> <delivery>

ARGUMENTS:
  <webhook>               Webhook ID.
  <delivery>              Delivery ID.

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --version               Show the version.
  -h, --help              Show help information.
