OVERVIEW: Attestation totals, success rate, unique devices, average risk, and
the latest events.

USAGE: grantiva console analytics overview [--json] [--verbose] [--quiet] [--days <days>] [--period <period>]

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --days <days>           Window in days. Default 30.
  --period <period>       Window: 1d, 7d, 30d, or 90d. Default 30d. (values:
                          1d, 7d, 30d, 90d)
  --version               Show the version.
  -h, --help              Show help information.
