OVERVIEW: Work support tickets: list, read the conversation, reply, set status
and priority.

USAGE: grantiva console support <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  list                    List tickets, most recently updated first.
  get                     Show a ticket with its full conversation.
  reply                   Reply to a ticket as the team. Moves it to
                          awaiting_reply and emails the submitter if that
                          notification is on.
  set-status              Change a ticket's status. Resolving emails the
                          submitter if that notification is on.
  set-priority            Change a ticket's priority.

  See 'grantiva help console support <subcommand>' for detailed help.
