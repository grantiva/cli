OVERVIEW: Hide a note from devices. Devices that already read it are not shown
it again on republish.

USAGE: grantiva console releases unpublish [--json] [--verbose] [--quiet] <note>

ARGUMENTS:
  <note>                  Release note ID.

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --version               Show the version.
  -h, --help              Show help information.
