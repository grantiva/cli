OVERVIEW: Change a ticket's priority.

USAGE: grantiva console support set-priority [--json] [--verbose] [--quiet] <ticket> <priority>

ARGUMENTS:
  <ticket>                Ticket ID.
  <priority>              New priority: low, normal, high, urgent. (values:
                          low, normal, high, urgent)

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --version               Show the version.
  -h, --help              Show help information.
