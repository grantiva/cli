OVERVIEW: Stop accepting attestations from this app. The primary app cannot be
deactivated.

USAGE: grantiva console apps deactivate [--json] [--verbose] [--quiet] <app>

ARGUMENTS:
  <app>                   Bundle ID or app UUID.

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --version               Show the version.
  -h, --help              Show help information.
