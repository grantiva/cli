OVERVIEW: List or inspect runs.

USAGE: grantiva console vrt runs <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  list                    List a project's runs, newest first.
  get                     Show a run with every screen's result and review
                          state.

  See 'grantiva help console vrt runs <subcommand>' for detailed help.
