OVERVIEW: Kill emulators Grantiva started: one by serial, or all of them. Stops
the UIAutomator2 server and removes the serial's adb forwards first.

A runner session on a torn-down serial (`grantiva runner start` or `grantiva
run --keep-alive`) is stopped too, and its session files are removed; --json
reports it as runnerSessionStopped. The guest's writes are flushed (`adb shell
sync`) before the emulator is killed, so an app installed just before survives
the next boot. Session files of a runner that had already died, and the temp
directories of a killed run on the serial, are removed and listed
(sessionFilesRemoved, temporaryDirectoriesRemoved).

USAGE: grantiva emulator teardown [--json] [--verbose] [--quiet] [--serial <serial>] [--all] [--force]

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --serial <serial>       Emulator serial to kill, e.g. emulator-5554.
  --all                   Kill every emulator Grantiva started.
  --force                 Kill the serial even though Grantiva did not start it.
  --version               Show the version.
  -h, --help              Show help information.
