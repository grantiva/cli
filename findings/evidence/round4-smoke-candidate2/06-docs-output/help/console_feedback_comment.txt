OVERVIEW: Reply on a feature request as the team. Devices following the thread
get a push.

USAGE: grantiva console feedback comment [--json] [--verbose] [--quiet] <request> --body <body>

ARGUMENTS:
  <request>               Feature request ID.

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --body <body>           Comment text, inline or @file.
  --version               Show the version.
  -h, --help              Show help information.
