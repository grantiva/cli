OVERVIEW: Export devices or events as CSV, to stdout or a file.

The export is always CSV (up to 10,000 rows). Without --out the CSV is written
to stdout, so `grantiva console analytics export --data events > events.csv`
works. --json reports what was written and requires --out.

USAGE: grantiva console analytics export [--json] [--verbose] [--quiet] --data <data> [--period <period>] [--out <out>]

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --data <data>           Which dataset: devices or events. (values: devices,
                          events)
  --period <period>       Window for the events export: 1d, 7d, 30d, or 90d.
                          Default 30d. Ignored for devices. (values: 1d, 7d,
                          30d, 90d)
  --out <out>             Write the CSV to this path instead of stdout.
  --version               Show the version.
  -h, --help              Show help information.
