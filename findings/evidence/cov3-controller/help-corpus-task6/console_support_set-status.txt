OVERVIEW: Change a ticket's status. Resolving emails the submitter if that
notification is on.

USAGE: grantiva console support set-status [--json] [--verbose] [--quiet] <ticket> <status>

ARGUMENTS:
  <ticket>                Ticket ID.
  <status>                New status: open, awaiting_reply, resolved, closed.
                          (values: open, awaiting_reply, resolved, closed)

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --version               Show the version.
  -h, --help              Show help information.
