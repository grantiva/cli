OVERVIEW: Show a flag's most recent recorded evaluations.

USAGE: grantiva console flags evaluations [--json] [--verbose] [--quiet] <key> [--limit <limit>]

ARGUMENTS:
  <key>                   Flag key (or UUID).

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --limit <limit>         Maximum entries to return, 1–200. Default 50.
  --version               Show the version.
  -h, --help              Show help information.
