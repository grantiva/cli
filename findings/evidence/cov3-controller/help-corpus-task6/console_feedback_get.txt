OVERVIEW: Show a feature request with its comment thread.

USAGE: grantiva console feedback get [--json] [--verbose] [--quiet] <request>

ARGUMENTS:
  <request>               Feature request ID.

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --version               Show the version.
  -h, --help              Show help information.
