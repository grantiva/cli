OVERVIEW: Accept a screen's new capture; it becomes the baseline on approval.

USAGE: grantiva console vrt screen accept [--json] [--verbose] [--quiet] <project> <run> <screens> ...

ARGUMENTS:
  <project>               Project slug.
  <run>                   Run ID.
  <screens>               Screen name(s).

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --version               Show the version.
  -h, --help              Show help information.
