OVERVIEW: Delete an AVD Grantiva created. Others need --force. A running AVD is
never deleted.

USAGE: grantiva emulator delete [--json] [--verbose] [--quiet] --name <name> [--force]

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --name <name>           AVD name to delete.
  --force                 Delete an AVD Grantiva did not create.
  --version               Show the version.
  -h, --help              Show help information.
