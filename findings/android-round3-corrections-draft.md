## B2-K19 compound closure

The replacement above is intentionally compound. It does not use Android CI's unsupported status to waive run/diff output behavior: run failure JSON and quiet handling come from `JSON-fail` and `AND-137-quiet-fail`; stable run and capture/diff modes come from AND-137/138/139; and the CI evidence is limited to its documented refusal, nonzero status, and absence of side effects. Remote authentication behavior remains outside the Android local-only command path and must be described as unavailable, not counted as a successful runtime variant.
