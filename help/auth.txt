OVERVIEW: Manage authentication with Grantiva.

USAGE: grantiva auth <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  login                   Authenticate with Grantiva API.
  status                  Show current authentication status.
  logout                  Remove saved authentication credentials.

  See 'grantiva help auth <subcommand>' for detailed help.
