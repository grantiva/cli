OVERVIEW: Create a flag environment.

USAGE: grantiva console envs create [--json] [--verbose] [--quiet] <name> [--color <color>]

ARGUMENTS:
  <name>                  Environment name, e.g. "Staging".

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --color <color>         Display color as a hex code, e.g. #f59e0b.
  --version               Show the version.
  -h, --help              Show help information.
