OVERVIEW: The Grantiva CLI for iOS developers.

USAGE: grantiva <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  build                   Build and optionally install the app to a simulator.
  run                     Run Maestro flows against a simulator. No visual
                          regression — reports step pass/fail and captures a
                          screenshot on failure.
  record                  Record a simulator or emulator and extract PNG frames
                          at exact requested timestamps.
  simulator               Provision, inspect, and tear down managed simulators.
  emulator                Provision, inspect, and tear down Android emulators.
  hierarchy               Dump the UI hierarchy of a booted simulator or
                          emulator without relaunching the app.
  ci                      CI pipeline — capture, compare, and upload results.
  diff                    Visual regression testing — capture, compare, and
                          approve screenshots.
  auth                    Manage authentication with Grantiva.
  console                 Manage your Grantiva dashboard from the terminal.
  doctor                  Check environment and dependencies.
  runner                  Manage the embedded UI automation runner.
  init                    Generate grantiva.yml (iOS) or grantiva-android.yml
                          (Android) in the current directory.
  mcp                     Start the Grantiva MCP server for AI agent
                          integration.

  See 'grantiva help <subcommand>' for detailed help.
