OVERVIEW: Force a flag value for one device.

USAGE: grantiva console flags overrides add [--json] [--verbose] [--quiet] <key> --device <device> --value <value> [--expires-at <expires-at>]

ARGUMENTS:
  <key>                   Flag key (or UUID).

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --device <device>       Device key ID to override for.
  --value <value>         Value to force for this device.
  --expires-at <expires-at>
                          Expiry as ISO8601 (default: never expires).
  --version               Show the version.
  -h, --help              Show help information.
