OVERVIEW: List audit entries, newest first.

USAGE: grantiva console audit list [--json] [--verbose] [--quiet] [--page <page>] [--per <per>]

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --page <page>           Page number, starting at 1.
  --per <per>             Entries per page, 1–100. Default 50.
  --version               Show the version.
  -h, --help              Show help information.
