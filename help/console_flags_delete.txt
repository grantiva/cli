OVERVIEW: Delete a flag, its rules, and its overrides.

USAGE: grantiva console flags delete [--json] [--verbose] [--quiet] <key> [--yes]

ARGUMENTS:
  <key>                   Flag key (or UUID).

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --yes                   Skip the confirmation prompt (required when stdin is
                          not a TTY).
  --version               Show the version.
  -h, --help              Show help information.
