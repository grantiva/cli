OVERVIEW: Manage flag environments (production, staging, ...).

USAGE: grantiva console envs <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  list                    List flag environments in sort order.
  create                  Create a flag environment.
  update                  Rename or recolor a flag environment.
  delete                  Delete a flag environment and its per-environment
                          values.
  reorder                 Move a flag environment up or down in the sort order.

  See 'grantiva help console envs <subcommand>' for detailed help.
