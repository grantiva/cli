OVERVIEW: Build and optionally install the app to a simulator.

USAGE: grantiva build <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  build (default)         Build the app for a simulator using xcodebuild.
  install                 Build and install the app on a simulator, then
                          optionally launch it.

  See 'grantiva help build <subcommand>' for detailed help.
