OVERVIEW: Manage the embedded UI automation runner.

USAGE: grantiva runner <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  install                 Extract or update the embedded runner binary.
  version                 Show the embedded runner version.
  start                   Start the runner with WDA and keep it alive for
                          interactive use.
  stop                    Stop the running runner session.
  dump-hierarchy          Dump the view hierarchy from a running app for agent
                          inspection.

  See 'grantiva help runner <subcommand>' for detailed help.
