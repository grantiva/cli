OVERVIEW: Triage feature requests: list, read the thread, set status, reply as
the team.

USAGE: grantiva console feedback <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  list                    List feature requests, most voted first.
  get                     Show a feature request with its comment thread.
  set-status              Change a feature request's status. The org admin is
                          emailed if that notification is on.
  comment                 Reply on a feature request as the team. Devices
                          following the thread get a push.

  See 'grantiva help console feedback <subcommand>' for detailed help.
