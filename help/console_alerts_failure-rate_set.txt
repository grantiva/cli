OVERVIEW: Enable, disable, or tune the failure-rate alert.

USAGE: grantiva console alerts failure-rate set [--json] [--verbose] [--quiet] [--enabled] [--no-enabled] [--threshold <threshold>] [--min-attestations <min-attestations>]

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --enabled/--no-enabled  Turn the alert on or off.
  --threshold <threshold> Failure-rate percentage that triggers the alert, 5–50.
  --min-attestations <min-attestations>
                          Minimum attestations in the window before the rate
                          counts.
  --version               Show the version.
  -h, --help              Show help information.
