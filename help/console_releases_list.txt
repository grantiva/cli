OVERVIEW: List release notes, newest first.

USAGE: grantiva console releases list [--json] [--verbose] [--quiet] [--app <app>] [--page <page>] [--per <per>]

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --app <app>             Only notes for this app (bundle ID or UUID).
  --page <page>           Page number, starting at 1.
  --per <per>             Notes per page, 1–100. Default 20.
  --version               Show the version.
  -h, --help              Show help information.
