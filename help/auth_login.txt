OVERVIEW: Authenticate with Grantiva API.

USAGE: grantiva auth login [--json] [--verbose] [--quiet] [--api-key <api-key>] [--base-url <base-url>]

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --api-key <api-key>     API key for Grantiva (skip browser flow)
  --base-url <base-url>   Base URL for Grantiva API (default:
                          https://api.grantiva.io)
  --version               Show the version.
  -h, --help              Show help information.
