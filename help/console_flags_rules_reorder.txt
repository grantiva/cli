OVERVIEW: Reorder a flag's rules.

Pass every rule ID in the desired priority order (index 0 evaluates first).

USAGE: grantiva console flags rules reorder [--json] [--verbose] [--quiet] <key> <rule-ids> ...

ARGUMENTS:
  <key>                   Flag key (or UUID).
  <rule-ids>              All rule IDs, in the new priority order.

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --version               Show the version.
  -h, --help              Show help information.
