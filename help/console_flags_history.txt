OVERVIEW: Show a flag's change history.

USAGE: grantiva console flags history [--json] [--verbose] [--quiet] <key> [--limit <limit>] [--offset <offset>]

ARGUMENTS:
  <key>                   Flag key (or UUID).

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --limit <limit>         Maximum entries to return.
  --offset <offset>       Entries to skip (for paging).
  --version               Show the version.
  -h, --help              Show help information.
