OVERVIEW: Rename an app or change its description and toggles.

USAGE: grantiva console apps update [--json] [--verbose] [--quiet] <app> [--name <name>] [--description <description>] [--analytics] [--no-analytics] [--webhooks] [--no-webhooks]

ARGUMENTS:
  <app>                   Bundle ID or app UUID.

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --name <name>           New display name.
  --description <description>
                          New description.
  --analytics/--no-analytics
                          Enable or disable analytics for this app.
  --webhooks/--no-webhooks
                          Enable or disable webhooks for this app.
  --version               Show the version.
  -h, --help              Show help information.
