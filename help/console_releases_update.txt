OVERVIEW: Change a note's version, title, or body. Use publish/unpublish for
its state.

USAGE: grantiva console releases update [--json] [--verbose] [--quiet] <note> [--version <version>] [--title <title>] [--body <body>]

ARGUMENTS:
  <note>                  Release note ID.

OPTIONS:
  --json                  Output as JSON
  --verbose               Print diagnostic detail (timestamps, labels,
                          metadata) to stderr.
  --quiet                 Silence progress diagnostics on stderr; warnings and
                          errors still print. Program output on stdout is
                          unaffected.
  --version <version>     New version.
  --title <title>         New title.
  --body <body>           New body, inline or @file.md.
  --version               Show the version.
  -h, --help              Show help information.
